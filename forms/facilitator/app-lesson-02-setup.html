App setup

Decision: The app does not replace Lesson 2. Barb is the coach. ChatGPT is the tool. The win is one useful answer. Do not connect the ChatGPT API for this. Learners already do not need to download the ChatGPT app — they open a browser to chatgpt.com.

Flow: App (Barb) → button “Open ChatGPT” → chatgpt.com in a new tab → Stay logged out → type in ChatGPT’s box. Leave Barb’s tab open so she can still help.

Step 1 — Open the tool (first real screen)

Barb photo. One sentence: “Today you will ask one real question and get an answer. That is the whole lesson.” One primary button. No WIOA, no $18K, no Book a Call on this screen.

Barb says: You are not late. Most people your age have never done this. We are going to open ChatGPT. You do not need an account. If a box asks you to log in, look for Stay logged out.

  1. Tap Open ChatGPT. Link: https://chatgpt.com · open in a new tab.
  2. If a login wall appears, point at Stay logged out / Continue without an account.
  3. Point at the message box: “That bar is where you type. If typing is hard, tap the microphone.”
  4. Always visible: Do not type your Social Security number, bank numbers, or passwords.
  5. When the box is ready: I’m in — ask my first question → (that is Step 2).

Done when they can see the ChatGPT message box. They have not asked a question yet.

How to set this up (no API)
  1. Create a page: Talk to AI / Lesson 2 · Step 1. Example URL: /talk-to-ai/ or /ask-barb/lesson-2/.
  2. Change the Ask Barb landing button “Talk to Barb Now” so it goes to that page — not a separate chatbot.
  3. On the page: Barb photo, the Step 1 copy, safety line, Open ChatGPT button.
  4. Button link = https://chatgpt.com · Open in new tab = On.
  5. Do not iframe or embed chatgpt.com. ChatGPT blocks that. New tab only.
  6. Do not add an OpenAI API key. No billing. No “Barb chat” widget for Lesson 2.

HTML for the button

Paste into a Custom HTML block. Large type. New tab.

<a href="https://chatgpt.com" target="_blank" rel="noopener noreferrer">Open ChatGPT →</a>
Tell them: A new tab will open. Leave this tab open so Barb can still help you.

Step 2 (same page, same day)

Starter prompt to copy and paste into ChatGPT:

I am over 50 and new to AI. I want to use it for something practical in my life. Explain the most useful thing I can do with it today, in five short steps, in plain language.

Add a Copy button if you can. They paste into ChatGPT’s box. Still no API.

Test on a phone
  • iPhone Safari and Android Chrome: tap Open ChatGPT → chatgpt.com opens.
  • Stay logged out is findable. No app download. No API key asked.
  • Barb’s page is still there when they switch back.
  • If your region requires login: “Free account with email is OK. You still do not need the ChatGPT app.”

Do not: Make Barb the only chat box. Lead with Health & Medications. Put $18K / WIOA / Book a Call on Step 1. Iframe ChatGPT. Connect the API “so they don’t have to download” — they never needed a download.

Done: Pioneer taps Talk to Barb Now → Step 1 → Open ChatGPT → chatgpt.com → types the starter prompt. That is the app supporting Lesson 2.
