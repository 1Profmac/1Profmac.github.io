# How to print the Facilitator Folder

50+TechBridge · Learn More Technologies  
Print from the **sheet that opens**, not from the dark hub page. The hub is only the menu.

---

## Fastest path

1. Open the hub: https://1profmac.github.io/forms/facilitator/index.html
2. Click **Open & Print →** on the card you want (Talk to AI, take-home card, session script, spine, survey).
3. On the next page, click the purple **Print This Sheet** button.
4. In the print dialog:
   - Paper: **Letter (8.5 × 11)**
   - Margins: **Default**
   - Scale: **100%**
   - Turn **Background graphics** on (Chrome: More settings → Background graphics). That keeps the navy headers.
5. Choose the printer, or **Save as PDF** / **Microsoft Print to PDF**.

Do that once per card. Do not print the yellow-box hub page. That is not a handout.

---

## If “Open & Print” says the file couldn’t be accessed

The hub loaded. The other files did not.

1. Download https://1profmac.github.io/forms/facilitator-kit.zip
2. Unzip it.
3. Open **`facilitator/index.html`** from the unzipped folder (double-click — Chrome or Edge).
4. Use the same steps: **Open & Print →** then **Print This Sheet**.

Do not print from inside the zip. Unzip first.

## Settings that usually break the page

- Firefox sometimes drops the colors. Use **Chrome** or **Edge**.
- “Fit to page” or 80% scale shrinks the large type. Use **100%**.
- Printing the dark hub page wastes ink and is the wrong document.

Ops forms (sign-in, photo release) are one folder up: https://1profmac.github.io/forms/index.html — same **Print This Sheet** pattern.
