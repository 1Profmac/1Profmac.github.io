Build recipe

What you are building: five website pages that walk a Pioneer through Lesson 2. Barb’s page stays open. ChatGPT opens in a new tab. You do not connect OpenAI. You do not embed ChatGPT. You do not put the app in the Apple/Google store for Week 1.

A working copy already lives in this repo: talk-to-ai/ (open talk-to-ai/index.html in Chrome). Use that as the app, or copy each screen into WordPress. Point “Talk to Barb Now” to that Welcome page — not to a chat widget.

The only technical rule

The Open ChatGPT button must be a normal link: https://chatgpt.com, set to open in a new tab. ChatGPT blocks iframes. An API key would turn Barb into a different chatbot and fight the lesson.

Build recipe
If you use WordPress / Elementor (live Ask Barb site)
  1. In Pages → Add New, create five pages with the titles above. Publish them.
  2. On each page: Barb photo (file: talk-to-ai/barb.png — same portrait as learnmoretechnologies.com/images/barb.png), large type, one main button, and a how-to phone next to the screen showing what to tap. Nothing about WIOA.
  3. On page 1, add a Button widget. Link = https://chatgpt.com. In the link options, turn on Open in new tab.
  4. On page 4, upload the seal (forms/facilitator/assets/agentic50-seal.png) and the two PDFs (completion slip + take-home).
  5. Edit the current “Talk to Barb Now” button. Change its link from the chatbot to /talk-to-ai/ (page 0). Hide Health / Money / Safety as the first topics. Hide $18K / Book a Call from that landing.
  6. Do not add an OpenAI API key, a chat plugin, or an HTML embed of chatgpt.com.
If you use this GitHub site instead

The five pages are already written in talk-to-ai/. After this branch is on the web, open /talk-to-ai/ on the GitHub Pages site. Until then, on your PC: download the folder, double-click index.html, and walk the five screens in Chrome.

HTML for the only special button

Paste into a Custom HTML block on page 1 if the Button widget will not open a new tab:

<a href="https://chatgpt.com" target="_blank" rel="noopener noreferrer">Open ChatGPT →</a>

Done when you can do this on a phone
  1. Tap Talk to Barb Now (or open /talk-to-ai/) → pick a goal.
  2. Tap Open ChatGPT → chatgpt.com opens in a new tab. Stay logged out is findable.
  3. Switch back to Barb. Copy the starter. Paste it in ChatGPT. Send a follow-up.
  4. On Save the win, the #AGENTIC50 seal is on screen. The completion slip PDF opens.

Do not build: a Barb chat box that answers questions; a Health & Medications home screen; WIOA / $18K on Step 1; an iframe of ChatGPT; an OpenAI key “so they don’t have to download” (they never needed a download); renaming the first screen “#AGENTIC50.”

Boards: the app is these five pages plus the printed slip. That is enough to demo in 8 minutes. License later. Do not wait for an App Store listing.
