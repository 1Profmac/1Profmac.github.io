Program & Course Structure

One curriculum, three delivery modes — not two different products. Adults 50+ finish when every session produces one win on their own device. The program is the cohort wrapper boards and HR buy. The course is the six modules the learner does.

Live Session Script — 110 Minutes
  1. Arrive and settle (10) — names, what worked last week, devices on
  2. One story, one rule (10) — why this matters at 50+; no theory dump
  3. I do (15) — facilitator demos slowly on a big screen
  4. We do (25) — class does the same steps together
  5. You do (30) — they complete it on their phone or laptop
  6. Save the win (10) — write the steps on a one-page take-home card
  7. Confidence check (10) — 3-question exit slip + next week preview

Build this

  • One tool per module
  • Their device, not a lab PC
  • Same 5 steps, three times
  • Printed one-pager, EN/ES, large type
  • Attendance + completion checkbox
  • Peer facilitator script
  • ~18 lessons total, not 40

Leave out of the core

  • How the internet or LLMs work
  • Coding or “become an AI engineer”
  • Ten apps in one day
  • Crypto, gold, or side-hustle schemes
  • Medical or legal advice from the AI
  • Shame language (“even grandma…”)
  • A fourth curriculum per buyer

Monetization fit: Free self-paced unlocks Modules 0–2. Certificate + Modules 3–6 run in a cohort or membership. Employer SKU = Core + Workplace AI fork + outcomes report. WIOA SKU = Core + Job Search fork + attendance/ITA packet. If you only build one thing next: six identical module templates, one week-5 fork, and this session script.
